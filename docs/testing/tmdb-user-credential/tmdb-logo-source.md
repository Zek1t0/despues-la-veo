# Fuente del logo TMDB

- Asset elegido: `Primary full (blue)`, logo aprobado publicado por TMDB.
- Página oficial: https://www.themoviedb.org/about/logos-attribution
- SVG oficial de origen: https://www.themoviedb.org/assets/2/v4/logos/v2/blue_square_2-d537fb228cf3ded904ef09b136fe3fec72548ebc1fea3fbbd1ad9e36364db38b.svg
- Documentación oficial de attribution: https://developer.themoviedb.org/docs/faq
- Términos oficiales aplicables al uso y attribution de la API: https://www.themoviedb.org/api-terms-of-use
- Archivo incorporado: `assets/tmdb-primary-full-blue.png`.

TMDB publica este asset como uno de sus logos aprobados para identificar el uso de la API, sujeto a sus términos y reglas de attribution. El SVG oficial tiene `viewBox="0 0 185.04 133.4"`. Se rasterizó una sola vez a PNG transparente de 370 × 267 para que React Native pueda mostrarlo en Android, iOS y web sin agregar una dependencia SVG. No se redibujó, recoloreó, recortó, giró ni deformó; se conservaron sus colores y proporción. La pantalla limita su tamaño para mantenerlo menos prominente que la identidad de la aplicación.
